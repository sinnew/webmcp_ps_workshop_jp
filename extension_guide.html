Chrome Extension & Built-in AI Field Guide

Keyword cheat sheet for Manifest V3 permissions (Track A vs. Track B), on-device Gemini Nano (LanguageModel) gotchas, and WebMCP UI synchronization rules.

🔑

1. Manifest V3 Architecture: Track A vs. Track B

Compare permission scope and architecture between declarative tool injection (Track A) and full-stack Side Panel agents (Track B):

Track A: Tool Injector (Fast-Track)

Declarative Content Script Injection

Injects WebMCP tools (document.modelContext.registerTool) directly into web pages. Zero host permissions required.

Track A manifest.json:
{
  "manifest_version": 3,
  "name": "WebMCP Injector",
  "version": "1.0",
  "content_scripts": [{
    "matches": ["https://*.example-store.com/*", "http://localhost:*/*"],
    "js": ["tools.js"],
    "world": "MAIN",
    "run_at": "document_idle"
  }]
}
✅ Must-Have: "world": "MAIN" registers tools in the page's actual JS context rather than isolated extension world.
Track B: Full-Stack AI Agent (Advanced)

Explicit Permissions Required

Hosts a Side Panel chat UI powered by local Gemini Nano that inspects and invokes WebMCP tools on the active tab:

Permission Why It Is Required
"sidePanel" Side Panel API: Displays sidepanel.html chat UI
"tabs" Tab ID Lookup: Targets active tab for tool execution
"scripting" Script Execution: Calls tools in page via executeScript
host_permissions Cross-Origin Access: Required because Side Panel clicks do not trigger activeTab
Minimal Track B manifest.json:
{
  "manifest_version": 3,
  "name": "WebMCP AI Agent",
  "version": "1.0",
  "permissions": ["sidePanel", "tabs", "scripting"],
  "host_permissions": ["<all_urls>"],
  "side_panel": { "default_path": "sidepanel.html" }
}
⚠️ Gotcha #1: The `activeTab` Trap in Side Panels
Clicking a button inside an extension Side Panel does NOT grant activeTab access to the page. Always declare "tabs", "scripting", and "host_permissions" in Track B!

2. Built-in AI (`LanguageModel` API) Critical Gotchas

1. Chrome Canary 154+ Required & Top-Level `LanguageModel` Global

Use Chrome Canary 154+ for async registerTool() Promises and native DevTools > Application > WebMCP panel. Use top-level LanguageModel.create() instead of legacy window.ai. 

const session = await LanguageModel.create({
  systemPrompt: "You are an in-browser WebMCP agent."
});

2. Streaming Yields Delta Chunks (`+=` Append, Do Not Overwrite!)

session.promptStreaming() yields delta tokens per iteration. Always append with += instead of overwriting with =. 

for await (const delta of session.promptStreaming(userPrompt)) {
  outputEl.textContent += delta; // ✅ Append delta token
}

3. Always Free GPU VRAM (`session.destroy()`)

Each Gemini Nano session consumes laptop VRAM/RAM. Always call session.destroy() when resetting or closing the chat.

⚡

3. WebMCP Execution & UI Synchronization Gotchas

1. Calling WebMCP Tools from Side Panel (`world: "MAIN"`)

To call page-registered WebMCP tools from an extension Side Panel, execute inside world: "MAIN": 

const [res] = await chrome.scripting.executeScript({
  target: { tabId: activeTab.id },
  world: "MAIN",
  func: async (name, args) => {
    const tool = (await document.modelContext.getTools()).find(t => t.name === name);
    return await tool.execute(args);
  },
  args: [toolName, toolArgs]
});

2. Enforce the <= 1.5 KB Token Budget Rule

Gemini Nano has a ~4K token window. Never return raw 30 KB API responses—filter outputs to top 3–5 items (<= 1.5 KB JSON).

3. Avoid the "Ghost Browser" Trap — Always Sync Visible UI

Never silently call fetch('/api/submit') while leaving the on-screen UI blank! Always update visible DOM state and use form.requestSubmit() or native <dialog> so Chrome Autofill, Password Manager, and user trust remain intact.

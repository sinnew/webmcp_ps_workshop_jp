🚩 Required Chrome Canary Flags Checklist

Open chrome://flags in Chrome Canary, enable the flags below, and relaunch your browser. (Note: Core LanguageModel is enabled by default). Progress is saved automatically.

  • 1. Enable WebMCP Testing Runtime
    Exposes the document.modelContext object and imperative/declarative tool APIs.
    chrome://flags/#enable-webmcp-testing Set to Enabled
  • 2. Enable Prompt API with Tool Use
    Enables native tool invocation (function calling) capabilities inside on-device Gemini Nano.
    chrome://flags/#prompt-api-tool-use Set to Enabled
  • 3. Enable Prompt API Multimodal Input (Optional / Bonus)
    Allows passing HTML <canvas> and <img> tokens directly to Gemini Nano.
    chrome://flags/#prompt-api-multimodal-input Set to Enabled
  • 4. Relaunch Chrome Canary
    Click the blue "Relaunch" button at the bottom right of the chrome://flags tab to activate changes.

⚡ Modern Web Guidance (MWG) Installation Hub

Install Google's official Modern Web Guidance skills into your AI agent or IDE so it generates modern, standards-compliant web code.

Install Modern Web Guidance into Cursor to automatically inject modern web baseline standards into Cursor Composer and Agent: 

npx modern-web-guidance@latest install

Tip: If developing Chrome extensions, run with --choose for interactive selection: npx modern-web-guidance@latest install --choose

In Claude Code terminal, add the plugin from the marketplace: 

/plugin marketplace add GoogleChrome/modern-web-guidance
/plugin install modern-web-guidance@googlechrome
/reload-plugins

Or install using the Vercel Skills CLI: 

npx skills add GoogleChrome/modern-web-guidance

For GitHub Copilot CLI or GitHub Extensions: 

gh skill install GoogleChrome/modern-web-guidance

Or in Copilot CLI: 

/plugin marketplace add GoogleChrome/modern-web-guidance
/plugin install modern-web-guidance@googlechrome

In Google Project IDX terminal or Antigravity environment: 

agy plugin install https://github.com/GoogleChrome/modern-web-guidance

In IntelliJ IDEA, WebStorm, or PyCharm:

  1. Open Settings / Preferences (Cmd+, or Ctrl+Alt+S).
  2. Navigate to Tools ➡️ AI Assistant ➡️ Skills.
  3. Click + (Add Skill) and search for Modern Web Guidance.

Use the universal CLI directly from any terminal: 

# Search best practices for a specific topic
npx -y modern-web-guidance@latest search "tabs popover dialog"

# Retrieve full markdown implementation guide
npx -y modern-web-guidance@latest retrieve "popover-api-dialog"

✅ How to Confirm Your Installation

  • 1. Quick Terminal Check (Ground Truth): Run npx modern-web-guidance@latest search "animate a dialog". If working, it immediately returns matching JSON guide metadata (e.g. animate-to-from-top-layer).
  • 2. In-Agent Test Prompt: In Cursor Composer, Claude Code, or Copilot, ask:
    "Using Modern Web Guidance, how should I animate a modal dialog entering the top layer?"
    A properly configured agent will query MWG and suggest native modern APIs (<dialog closedby>, @starting-style, transition-behavior: allow-discrete) rather than legacy JavaScript polyfills.
  • 3. Agent Activation Tip: If your agent does not trigger guidance automatically, simply append "use modern-web-guidance" to the end of your prompt, or use slash command syntax if supported (e.g. /modern-web-guidance).

🛠️ Chrome DevTools MCP Server Setup

Connects your external AI coding assistant directly into Chrome Canary via Chrome DevTools Protocol (CDP) for live inspection, screenshot captures, console logs, and DOM validation. 

npx -y chrome-devtools-mcp@latest

Claude Code CLI 1-liner: 

claude mcp add chrome-devtools npx chrome-devtools-mcp@latest

MCP Configuration snippet (e.g. for Cursor ~/.cursor/mcp.json or Claude Desktop): 

{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp@latest"]
    }
  }
}
